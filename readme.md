### **实验记录与修改说明书**

#### **一、 代码修改详情**

**1. `train.py` (训练逻辑优化)**

* **加入 SWD Loss (Sliced Wasserstein Distance)**
* **相较于 Gram Loss 的优势**：
* **高阶统计量对齐**：Gram 仅对齐特征的二阶协方差（形状/方向），假设分布近似高斯；SWD 通过投影排序，能对齐任意复杂分布（如多峰、长尾）的形状（直方图），对色彩和纹理的还原更精准。
* **数值稳定性**：Gram 涉及特征值的平方计算，容易梯度爆炸；SWD 是线性的距离计算，梯度平滑且鲁棒。


* **与 FFT Loss、Cos_Sim 之间的互补特点**：
* **FFT (频谱)**：负责“**清晰度**”，防止生成图像模糊，保证高频能量。
* **Cos_Sim (方向)**：负责“**优化轨迹**”，保证梯度方向正确，辅助收敛。
* **SWD (分布)**：负责“**风格神韵**”，保证生成的纹理统计规律（如笔触密度、色调分布）与目标一致。三者缺一不可。




* **加入 OT (Optimal Transport / 最优传输)**
* **在 batch_size=64 上为什么可行**：
* 64 属于“甜点区间”。样本量足够提供统计上的多样性，使得 Sinkhorn 算法能找到有意义的近邻匹配；同时计算量小（64x64 矩阵），单卡显存完全可承受，不会拖慢训练。


* **它的作用**：
* **几何拉直 (Trajectory Straightening)**：通过将内容图与几何上最近的风格图配对，迫使 Flow Matching 学习最短路径。这直接导致**训练极速收敛**，Loss 下降更快，且生成的中间状态更稳定。





**2. `SAFlow.py` (模型架构升级)**

* **将 t_emb 和 s_emb 从原先的相加改成了拼接 (Concat)**
* **解决的问题**：解决了**特征淹没**问题。原先的加法 (`+`) 可能导致数值较大的时间信号掩盖了微弱的风格信号；改为拼接后，后续的 MLP (AdaGN) 能通过独立的权重矩阵分别提取时间和风格特征，实现了**条件解耦**，显著增强了风格控制力。



**3. `auto_search.py` (自动化消融实验)**

* **实验设计与目的**：
* **E1 vs A3 (SWD有效性)**：对比开启与关闭 SWD，验证其是否是生成具体笔触纹理的关键（而非仅仅改变色调）。
* **E1 vs E2/E3 (SWD可控性)**：测试 SWD 权重 (10->50->100) 对风格化强度的线性控制能力，验证方法的鲁棒性。
* **E1 vs E5 (OT有效性)**：对比开启与关闭 OT，通过 Loss 曲线验证 OT 是否显著加速了模型收敛。
* **E1 vs E4 (Patch大小影响)**：对比 Patch=7 和 Patch=3，验证感受野对纹理粒度（细腻度 vs 结构感）的影响。
* **E6 (寻找 SOTA)**：在高结构约束 (MSE) 和高风格约束 (SWD) 之间寻找最佳平衡点，冲击最佳视觉效果。

#### **二、 未来可能的修改方向**

**1. 是否需要使用 SD3 (Stable Diffusion 3)？**

* **可行性评估**：**极难**。
* SD3 (Medium 版) 参数量为 2B，架构为 DiT。在 8GB 显存的 4060 上，仅加载模型权重就需要约 4GB (FP16)，加上梯度、优化器状态 (AdamW) 和激活值，**显存会瞬间溢出 (OOM)**。
* 即使使用 LoRA + Gradient Checkpointing + 8-bit Optimizer，训练体验也会极差（Batch Size 只能开到 1，且极慢）。


* **建议**：在现有硬件下，坚持 **UNet/ResNet 架构** 是最优解，学术界对轻量化架构的创新同样认可。

**2. 是否需要进行比较大的重构，引入 Cross-Attn？**

* **决策依据**：**暂不需要，除非遇到瓶颈。**
* **AdaGN** (你现在的架构) 是**全局风格控制**的王者，对于统一笔触的风格迁移（如梵高、莫奈）效果极佳且计算快。
* **Cross-Attn** 擅长**局部语义对应**（如“让内容图的树对应风格图的树”）。


* **建议**：先跑通当前的 AdaGN + SWD。如果发现生成的图“风格是对的，但物体错位了（如把云画在了地上）”，再考虑引入 Cross-Attn 来增强语义对齐。对于当前阶段，AdaGN 足够发顶会。
